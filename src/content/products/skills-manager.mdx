    - type: faq
      title: 常见问题
      items:
          - q: 支持哪些工具？
            a: 目前覆盖 Claude Code、Codex、ZCode、Cursor、Qoder、OpenCode、Gemini CLI 和 GitHub Copilot 的用户级技能目录，并额外扫描部分工具的兼容目录（如 Cursor 会读取 ~/.agents/skills）。
          - q: 仓库内容更新后，工具里的副本会自动同步吗？
            a: 不会自动同步，避免意外覆盖。在仓库条目菜单点击「下发更新到工具」，即可覆盖同步所有安装过该 Skill 的目录——已同步副本按哈希比对自动跳过，失败时用备份回滚；项目里经仓库安装的 Skill 也支持一键从仓库更新。
          - q: 安装会移动或覆盖我的文件吗？
            a: 不会。中央仓库与工具目录是独立副本，安装是纯复制；安装前会检查目标工具能发现的全部已扫描目录，发现同名 Skill 时阻止重复安装。
          - q: 支持管理项目内的 Skill 吗？
            a: 支持。把项目文件夹添加进应用后，可扫描、查看、编辑、收录、删除项目内各 Agent 目录的 Skill，也能从仓库安装或更新；项目级目录支持除 ZCode 外的 7 个工具（ZCode 官方暂未定义项目级目录）。
          - q: 多个工具能共用一份 Skill 吗？
            a: 可以。共享目录中的文件只有一份，会同时出现在多个工具页面；卸载或删除时会列出所有读取此目录的工具，执行后这些工具都会失去这份发现结果，其他目录中的独立副本保留。
          - q: 误删了还能找回吗？
            a: 能。删除进入应用回收站，保留删除时间、来源与原路径，可还原到原位置；安装失败也会自动回滚，不影响原文件。
          - q: 仓库能放网盘同步目录吗？
            a: 可以。设置里可把中央仓库迁移到任意空文件夹（例如网盘同步目录），现有内容自动搬运，其他工具的共享目录发现路径也会跟随更新。
          - q: macOS 可以用吗？
            a: 可以。提供 macOS DMG 安装包（x64 与 arm64），与 Windows 版一起由发布流程自动构建；因未做签名与公证，首次打开若提示「应用已损坏」，按 README 中的 xattr 命令移除 quarantine 标记即可。
